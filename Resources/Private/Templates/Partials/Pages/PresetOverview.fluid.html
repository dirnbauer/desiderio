5 of the presets come from the create page on ui.shadcn.com and 10 are house presets generated against WCAG 2.2 contrast targets. Set one for a whole site with desiderio.shadcn.preset in the site settings, or for one page and everything below it with the Theme preset field in the page properties — it is inherited down the rootline, so a campaign subtree can run a different look inside the same install. Neither needs a rebuild: the tokens are runtime CSS custom properties. Anything you design on the create page yourself goes in as custom.
