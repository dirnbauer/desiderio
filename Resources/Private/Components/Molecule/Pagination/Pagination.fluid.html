Shared pager for the paginated plugin lists (EXT:news, EXT:blog). Page links are built with f:uri.action, so the component works for every Extbase plugin that paginates with a `currentPage` argument; pass the controller action through `actionName` when the list is not the default action. Callers hand over the numbers of the core PaginationInterface (allPageNumbers / displayPageNumbers, currentPageNumber, first/last, previous/next, hasLessPages/hasMorePages) rather than the pagination object itself, so one component serves both extensions' pagination types. EXT:solr keeps its own partial: its page URLs come from s:uri.paginate.resultPage(), a ViewHelper this component cannot reference without making EXT:solr a hard dependency.
