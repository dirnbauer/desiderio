Inert stand-in for the Friendly Captcha widget, shown when studiomitte/friendlycaptcha is not installed at all, and when the Desiderio bypass is active (Development context or test mode). The button is disabled and does nothing on purpose — it only tells the editor that a captcha sits here. Used by the TYPO3 Form Framework, Powermail and Blog captcha partials, which all render the same placeholder.
