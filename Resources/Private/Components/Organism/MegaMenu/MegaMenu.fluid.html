Mega menu after the shadcn/ui NavigationMenu recipe (ui.shadcn.com/docs/components/navigation-menu): a row of triggers, one per first-level page, each opening a content panel. The panel leads with a card for the first-level page itself: the recipe's feature link (muted gradient, brand mark, title and abstract), laid across the top of the panel so it never stretches into an empty block beside tall lists. Only that card carries an abstract; one title-only link per subpage follows, so a panel with 20 subpages stays a few rows tall. A subpage's own subpages follow its link as compact links. A first-level page without subpages is a plain link in trigger style. d:organism.siteHeader renders it inside its main-navigation landmark, in place of the main menu, on the site's root page when desiderio.navigation.megaMenu is "home". Disclosure pattern (desiderio.js section 6d): each trigger is a button with aria-expanded and aria-controls; links stay links. Up to 1024px the burger opens it as a stacked accordion, panels inline. The panels carry d-menu-surface--wide and d-menu-popover, so the menu colour and menu accent of the create page on ui.shadcn.com apply here as in the header's dropdowns. Items highlight with the menu accent instead of the recipe's bg-muted, which is what lets "bold" show at all. ctaSlug: the header-button page (desiderio.header.ctaSlug) stays in the list for the burger and hides on desktop, like in the main menu.
